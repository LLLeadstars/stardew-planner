# 星露谷商店的条件性交易窗口：罗宾周二案例

核查日期：2026-09-15  
目标版本：PC 原版 1.6.15（无 Mod）  
研究范围：仅核实木匠店周二的短暂交易技巧，以及影响这一技巧的最小状态集合。

## 结论

普通、非特殊日的周二，木匠店仍应视为“今日休息”。不过罗宾 9:30 开始前往皮埃尔杂货店，约 9:40 经过销售柜台；玩家若已进入房屋并守在柜台交互位，可在她经过或贴近柜台的短暂瞬间打开商店。这个行为适合建模为**条件性交易窗口**，不适合改写成正式营业时段。

界面建议表达为：

> 今日休息 · 技巧：约 9:40 在柜台等候，罗宾经过时可尝试交易

其中“约”和“可尝试”不可省略。资料只确认了一个与 NPC 路径相关的短暂机会，没有确认稳定的起止区间；玩家阻挡路径、进图时机和实际移动过程都可能使墙上时钟对应时刻漂移。

## 条件与例外

| 条件 | 对商店状态的影响 | 规划器应如何显示 |
| --- | --- | --- |
| 普通、非特殊日的周二 | 正式休息；约 9:40 有短暂柜台交易机会 | 红色“今日休息”，另加黄色“条件性技巧”提示，不把整日或 `9:40–9:50` 标绿 |
| 普通下雨的周二 | 雨天日程优先；罗宾 8:00 到柜台、17:00 离开，商店按普通时段营业 | 绿色 `9:00–17:00`；无需提示周二技巧 |
| 持有城镇钥匙 | 改变能否在锁门时进入建筑，不改变罗宾是否在柜台附近 | 单独作为“进门条件”；不能据此把休息日改为营业 |
| 未持有城镇钥匙 | 约 9:40 的早间机会不受影响，因为房屋通常 9:00 已可进入 | 不应把钥匙设为早间技巧的前置条件 |
| 罗宾正在农场施工 | 罗宾不在店内，商店全天关闭 | 隐藏或禁用柜台技巧，并说明“罗宾正在施工” |
| 多数节日 | 建筑不可进入，城镇钥匙也不生效 | 标为确定不可用 |
| 姜岛度假村已解锁，但当天是否出行未知 | 罗宾可能随机在周二去度假，普通周二路线不再可靠 | 标为未知并提示当天复核；不能保证 9:40 或约 20:00 的窗口 |
| 绿雨或其他特殊日程 | 可能覆盖普通雨天或周二日程 | 不与普通 `rain` 合并；按更高优先级的特殊日程判断 |

另有一个相关但同样不稳定的机会：普通周二罗宾约 20:00 回家并经过柜台时，也可能短暂交易。没有钥匙时，玩家通常需要在建筑锁门前已经进入并等候；有钥匙可改善进门条件，但仍须等罗宾靠近柜台。由于它依赖返程与进门时机，建议 V1 只作为次要技巧提示，不作为可靠计划窗口。

## 证据与置信度

### 中等：社区 Wiki 的固定修订

- [Robin，固定修订 191769](https://stardewvalleywiki.com/mediawiki/index.php?title=Robin&oldid=191769)列出：普通周二 9:30 出发去皮埃尔，并明确说明约 9:40 经过收银台时可短暂使用商店；其雨天日程为 8:00 到柜台、17:00 离开，且页面说明雨天日程优先于普通周二日程。
- [Carpenter's Shop，固定修订 194219](https://stardewvalleywiki.com/mediawiki/index.php?title=Carpenter%27s_Shop&oldid=194219)明确写明周二关闭，但下雨例外；也记载约 9:40 经过柜台与约 20:00 回家时的短暂交易机会、施工期间全天关店，以及部分特殊日程的覆盖关系。
- [Key To The Town，固定修订 176345](https://stardewvalleywiki.com/mediawiki/index.php?title=Key_To_The_Town&oldid=176345)说明钥匙用于进入包括木匠店在内的建筑，同时列出节日期间不生效等限制。
- [Shop Schedules，固定修订 194214](https://stardewvalleywiki.com/mediawiki/index.php?title=Shop_Schedules&oldid=194214)进一步支持把“建筑可进入”和“店主可提供服务”作为两个条件处理。

这些页面基于社区维护，不是 ConcernedApe 的第一方规格。固定修订能避免页面以后变化，却不能消除社区资料可能出错的风险，因此本研究不把它们评为高置信度。

### 低至中等：官方站点上的玩家复现

- [Stardew Valley 官方论坛讨论：Robin's always on the job](https://forums.stardewvalley.net/threads/robins-always-on-the-job.8245/)记录了玩家在周二约 9:30 等候、罗宾经过柜台时成功打开商店的观察，也有其他玩家报告在她靠近柜台时交易及晚间路径上的相同行为。

论坛由官方站点承载，但帖子内容仍是玩家经验，不是开发者声明；它只能用来交叉印证 Wiki，不能单独确定 1.6.15 的精确窗口。

### 高可信但仅作版本背景：第一方补丁说明

- [Stardew Valley 1.6 完整更新说明](https://www.stardewvalley.net/stardew-valley-1-6-update-full-changelog/)与 [1.6.15 Steam 官方公告](https://steamcommunity.com/ogg/413150/announcements/detail/517448731263500641)没有记录对这一柜台交互或罗宾周二日程的改动。

补丁说明是第一方资料，但“未列出改动”只能作为旁证，不能证明这一技巧在 1.6.15 中必然有效。

## 尚未确认

本机未找到可供核查的 PC 1.6.15 游戏安装或已解包的原版日程数据，因此没有完成该版本的实机复现。以下细节必须保留为未知，待专门校准：

- 9:40 附近可交互的精确持续秒数或游戏内分钟数；
- 不同移动速度、路径阻挡、多人模式或进图时机造成的漂移；
- 所有输入设备上应点击罗宾本人还是收银台，抑或二者均可；
- 绿雨各年份、当天姜岛访客随机结果及其他特殊日程组合的完整优先级。

因此，规格用语应为“经社区资料支持，待 PC 原版 1.6.15 实机校准”，不能写成“官方确认”或“保证可交易”。

## 条件性交易窗口的最小字段

| 字段 | 用途 |
| --- | --- |
| `rule_id` | 标识该技巧规则，便于独立修订或停用 |
| `game_version`、`platform`、`mod_status` | 限定规则适用基线 |
| `game_date`、`weekday` | 判断周二及特殊日期 |
| `weather_kind` | 至少区分普通下雨、绿雨与非雨天 |
| `festival_or_special_day` | 表示会覆盖普通周二路线的高优先级日程 |
| `robin_working_on_farm` | 排除施工期间的柜台窗口 |
| `beach_resort_unlocked`、`actual_resort_visit` | 保存已知状态与可能到当天才确定的随机结果；后者允许“未知” |
| `has_key_to_town`、`door_access_mode` | 区分正常进门、提前在内和钥匙进门，不与服务状态混为一谈 |
| `npc_route_event` | 例如 `outbound_near_09_40` 或 `inbound_near_20_00` |
| `interaction_target`、`interaction_requirement` | 记录“柜台交互”与“罗宾须在柜台附近” |
| `window_kind`、`approximate_time` | 将其表达为约时瞬时窗口，而非稳定区间 |
| `availability_state` | 使用“可用、不可用、未知”；随机分支未确定时不得伪装成确定结果 |
| `confidence`、`source_revision`、`last_verified_version` | 向用户披露证据强度，并支持规则更新 |
| `fallback` | 条件不满足或未知时，按正式休息处理，同时保留非阻断的技巧提示 |

快速修改玩家状态时，应重新计算上述条件并显示变化预览。例如把天气从“未知”改为“普通下雨”后，可从“周二休息＋技巧提示”变为“9:00–17:00 正常营业”；把“罗宾正在施工”改为“是”后，则移除该日的柜台技巧。
