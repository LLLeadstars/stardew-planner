# PC 原版 1.6.15：铁匠铺工具升级数据矩阵

## 研究边界与证据等级

本文只为 V1 的“工具升级交付”“工具取回”和相关提醒提供数据，不扩展成完整攻略。目标版本为 **PC 原版 1.6.15**。

证据按以下优先级使用：

1. ConcernedApe 官网的 1.6 更新日志，用于确认 1.6 新增的淘盘升级；
2. 从 PC 1.6.15 本地游戏文件 `Data/Tools.json` 提取并标注版本的固定 Git 提交，用于核对工具 ID、等级与升级链；这仍是第三方提取物，不等同于官方公开数据；
3. Stardew Valley Wiki 的铁匠铺、工具和 Clint 页面，用于营业、节日与两天工期的玩家可见规则；Wiki 是社区资料，当前页面可能继续吸收 1.6.15 之后的改动，因此不把它单独作为精确实现的最终依据；
4. 一个未标明精确小版本的 1.6 反编译仓库，仅用于解释计数器和限制为何产生当前行为。它不能证明 1.6.15 没有边界差异。

## V1 可升级对象

| 工具 | 初始/最低状态 | 可选目标等级 | V1 说明 |
| --- | --- | --- | --- |
| 斧头 | 基础 | 铜 → 钢 → 金 → 铱 | 每次只能升一级 |
| 十字镐 | 基础 | 铜 → 钢 → 金 → 铱 | 每次只能升一级 |
| 锄头 | 基础 | 铜 → 钢 → 金 → 铱 | 每次只能升一级 |
| 喷壶 | 基础 | 铜 → 钢 → 金 → 铱 | 每次只能升一级；1.6.9 起升级后自动装满水 |
| 淘盘 | 铜淘盘 | 钢 → 金 → 铱 | 1.6 新增升级链；没有“基础 → 铜”的铁匠铺升级 |
| 垃圾桶 | 基础 | 铜 → 钢 → 金 → 铱 | 成本不同于其他工具；它是背包界面的垃圾桶能力，不是玩家携带的一件普通工具 |

依据：官网 [1.6 完整更新日志](https://www.stardewvalley.net/stardew-valley-1-6-update-full-changelog/) 明确新增钢、金、铱淘盘；固定提交中的 [PC 1.6.15 `Data/Tools` 提取结果](https://github.com/juliaramosguedes/stardew-data/blob/4e0d98119afefd766f15ee77a529db4eb71fa240/data/en-US/tools.json) 给出了各工具的 `upgradeLevel` 与 `upgradeFrom`；Wiki 的 [Blacksmith](https://stardewvalleywiki.com/Blacksmith) 页面将范围概括为四件主要工具、淘盘和垃圾桶，并说明等级不能跳过。

不纳入铁匠铺升级活动：镰刀、钓鱼竿、奶桶、剪刀、武器等。它们即使存在不同品质或获取路线，也不属于这条 Clint 工具升级链。

## 材料与费用矩阵

除垃圾桶外，斧头、十字镐、锄头、喷壶按下表升级；淘盘从钢级开始也使用同一目标等级价格。

| 目标等级 | 前置等级 | 材料 | 费用 |
| --- | --- | --- | ---: |
| 铜 | 基础 | 铜锭 ×5 | 2,000g |
| 钢 | 铜 | 铁锭 ×5 | 5,000g |
| 金 | 钢 | 金锭 ×5 | 10,000g |
| 铱 | 金 | 铱锭 ×5 | 25,000g |

淘盘的第一项是“铜淘盘 → 钢淘盘”，即铁锭 ×5、5,000g。

垃圾桶使用相同的目标等级材料，但费用减半：

| 目标等级 | 前置等级 | 材料 | 费用 |
| --- | --- | --- | ---: |
| 铜 | 基础 | 铜锭 ×5 | 1,000g |
| 钢 | 铜 | 铁锭 ×5 | 2,500g |
| 金 | 钢 | 金锭 ×5 | 5,000g |
| 铱 | 金 | 铱锭 ×5 | 12,500g |

价格与材料由 Wiki [Blacksmith 的升级表](https://stardewvalleywiki.com/Blacksmith#Upgrade_Tools) 和 `Data/Tools` 的常规升级模型相互印证。Modding Wiki 对 [`ConventionalUpgradeFrom` 的 1–4 级规则](https://wiki.stardewvalley.net/Modding:Tools#Upgrades) 还明确给出 2,000/5,000/10,000/25,000g 与对应 5 个金属锭的映射。垃圾桶是单独价格表，不能套用普通工具费用。

## 日期推进与工具升级状态

令成功交付日为 D：

| 游戏日 | 系统应显示的工具升级状态 | 玩家可用性 |
| --- | --- | --- |
| D（交付完成后） | 升级中，预计 D+2 完成 | 当天交付前仍可使用；交付后不在玩家手中 |
| D+1 | 升级中 | 不可使用 |
| D+2 清晨 | 待取回 | 尚未取回前不可使用；若柜台可交易，当天取回后可继续使用 |

“耗时 2 天”的实际含义是玩家在 D+1 和 D+2 早晨醒来时都没有工具；D+2 到店取回后可在当天剩余时间使用。Wiki 的 [Tools/Upgrades](https://stardewvalleywiki.com/Tools#Upgrades) 给出了这个玩家视角解释。反编译 1.6 代码在交付时把 `daysLeftForToolUpgrade` 设为 2，并在每日更新时减 1，可作为机制侧佐证，但该仓库没有声明精确为 1.6.15，故仍需实机回归。

节日不会暂停加工倒计时。因此：

- “完成日期”始终先按 D+2 计算；
- “最早可取回日期”是 D+2 或其后的首个柜台可交易日；
- 若 D+2 恰好是商店关闭的节日，只是无法当日取回，不应把完成日期顺延成 D+3；
- 游戏内的“工具已完成”通知在节日或部分 Clint 缺席日可能不出现或延后，V1 应根据状态与日期自行提醒，不能把是否弹出通知当成是否完工。

Wiki [Blacksmith](https://stardewvalleywiki.com/Blacksmith#Upgrade_Tools) 明确说明节日仍继续加工，并举出“节日前一天交付，节日后一天完成”和“完成日恰逢关闭则晚一天取回”的情形。

## 交付与取回窗口

### 可直接作为 V1 规则的基线

| 条件 | 交付/取回判断 | 建议提示 |
| --- | --- | --- |
| 普通常规日 | 09:00–16:00 | 绿色“可办理”；按到门时间判断 |
| 社区中心已修复后的周五，非雨天 | 不可办理 | 红色“Clint 不在店内” |
| 社区中心已修复后的周五，下雨 | 09:00–16:00 | 绿色“雨天照常办理” |
| 冬 16 日 | 09:00–10:30；之后不可办理 | 黄色强调“10:30 前办理” |
| 白天型节日导致商店关闭 | 不可办理，但加工继续 | 红色“节日关闭；升级进度不暂停” |

基线营业时间与关店摘要见 Wiki [Blacksmith](https://stardewvalleywiki.com/Blacksmith)；周五/天气与冬 16 日的 NPC 行程见 [Clint/Schedule](https://stardewvalleywiki.com/Clint#Schedule)。

### 需要条件化或暂缓自动判定的边界

| 条件 | 当前证据 | V1 处理 |
| --- | --- | --- |
| 玩家 16:00 前已进入店内 | Wiki 称门在 16:00 锁，但已在室内可在柜台继续交互，甚至 Clint 17:00 离柜后仍可能触发服务 | 不扩展绿色营业时间；可显示黄色技巧“已在店内时可能可继续办理”，待 1.6.15 实机确认具体截止点 |
| 月光水母起舞、万灵节等晚间节日 | 反编译的通用关店逻辑只在节日开始早于 19:00 时关闭商店；Wiki 也将部分晚间节日列为例外 | 使用逐节日白名单前先实测；不能简单采用“所有节日都关闭” |
| 沙漠节期间 | 铁匠铺建筑本身不按普通节日规则关闭，但 Clint 在春 16 日或作为节日商贩时可能离店 | 依赖巴士修复、具体日期/商贩轮值；V1 若未维护这些状态则标黄色“可能不在店”，不要显示确定可办理 |
| 姜岛海滩度假村已开放 | Clint 可能随机在周五前往度假村 | 未来日期无法仅靠静态状态确定；标黄色“可能离店”，当天由玩家快速确认/覆盖 |
| 第 1 年绿雨日 | Wiki 行程显示 Clint 离开铁匠铺前往酒吧 | 标红“Clint 不在店内”，但列入实机回归清单 |
| 小镇钥匙 | 只能改变进门限制，不能保证 Clint 在柜台或提供服务 | 不据此把卡片改成绿色；NPC 不在时仍不可交付/取回 |

交付和取回应共用同一个“柜台是否可交易”判断；不能只看建筑门是否能进入。取回还应提醒至少留一个背包空位；垃圾桶升级是否免于该限制由反编译代码暗示，但不应在完成实机验证前作为无条件规则。

## V1 数据字段与提醒边界

工具升级交付活动至少需要：

- 工具种类；
- 当前等级（来自玩家状态，可快速修改）；
- 目标等级（只能是下一等级）；
- 计划交付日期与时刻；
- 参考材料与费用；
- 当日柜台判断所需的游戏日、天气、社区中心状态，以及适用时的特殊日状态。

交付活动只有在玩家标记完成后，才把工具升级状态改为“升级中”，记录实际交付日并生成 D+2 完成日期。计划日期到达不代表已交付。

取回活动至少显示：

- 工具与目标等级；
- 完成日期与最早可取回日期；
- 当日柜台状态；
- 背包空位提醒；
- “完成取回后才更新工具等级”。

同一玩家同一时间只应存在一件“升级中/待取回”的工具。社区 Wiki 的 [1.6.3 版本历史](https://wiki.stardewvalley.net/Version_history#1.6.3) 记录了升级期间仍可购物和砸晶球；这不代表可以并行升级第二件工具。反编译代码以单个 `toolBeingUpgraded` 字段并在非空时阻止购买另一项升级，支持“一次一件”的规则，但需要 1.6.15 实机验证后再作为强校验。

## 必须实机验证的清单

在把黄色条件转为确定规则前，应使用 **PC 原版 1.6.15、无模组** 至少验证：

1. 六类对象逐级出现在升级菜单中，尤其是铜淘盘 → 钢淘盘、垃圾桶升级；
2. 每级扣除的材料与金币，以及不可跳级、一次只能升级一件；
3. D 日交付后 D+1/D+2 的计数、D+2 取回后状态更新、跨季/跨年是否一致；
4. D+1 或 D+2 遇到白天节日、晚间节日、沙漠节时，加工与可取回日期分别如何表现；
5. 社区中心修复后周五的晴/雨分支、冬 16 日 10:30 边界、第 1 年绿雨日；
6. 16:00 前已进店后实际可交付/取回的最晚时刻，以及小镇钥匙能否改变任何服务窗口；
7. 姜岛度假村导致 Clint 离店时，商店柜台、交付、取回分别如何表现；
8. 普通工具取回时背包已满，以及垃圾桶取回是否确实无需空位；
9. 节日或周五未弹“完成”通知时，工具是否已经处于可取回状态。

在这些验证完成前，V1 可以把材料、费用、D+2 完成日和常规 09:00–16:00 作为参考信息；涉及 NPC 行程、节日例外、16:00 后技巧和随机度假时，应显示来源与黄色不确定提示，允许玩家快速修改状态或覆盖判断。
