# V1 建图基线

本文件记录建图对话中用户已经确认的产品方向，不是 implementation-ready spec。
已转入 [GitHub 决策地图](https://github.com/LLLeadstars/stardew-planner/issues/1) 的 Notes。此文件仅为建图时的历史快照，后续范围变化以 GitHub 决策记录为准。

## 已确认的方向

- 产品是星露谷物语的手动日程规划工具。玩家决定活动、顺序与时间，系统提供信息和耗时辅助；V1 不自动排程，不主动优化日程。
- V1 主要用于进入一个游戏日之前规划当天。边玩边用和跨天规划是后续目标，不提前实现完整功能。
- 电脑优先的网页应用；手机端优化放到后续。
- 无账号，数据保存在当前浏览器，V1 包含导出、导入备份。云端保存与跨设备同步后续讨论。
- 游戏状态由玩家手动填写，保存已填信息。存档导入后续考虑。
- 日程中的时刻和时长统一采用游戏内时间。
- 内置活动和自定义活动并存，允许玩家修改用于规划的预计时长。
- 支持按工作量估算、按时间预留两种方式，按活动特点选择默认方式；具体对应关系未定。
- 长期目标由玩家创建、手动拆解或关联活动，记录完成情况；系统自动拆解后续考虑。目标支持不等于提前实现跨天日程界面。
- 提供参考信息与有明确依据的约束提醒，保留玩家的原安排，不强制阻止冲突。
- 玩家手动添加赶路活动并填写时长；根据地点估算移动耗时放到后续。
- 首批活动优先覆盖农场日常与城镇办事，例如浇水、收获、购物、工具升级。最终清单与支持参数待定。
- 钓鱼和采矿先支持玩家预留时间，其具体估算能力后续研究。
- 玩家排序的普通活动顺序衔接，同时支持固定开始时间的活动。自动衔接只计算时间，不替玩家选择或重排活动。
- 前序活动延长导致冲突时，固定活动的原时刻不变；显示重叠提醒，由玩家调整。前序提前结束时显示空闲时段。
- 内置信息与估算规则先针对一个明确的原版游戏版本，具体版本待核实。Mod 玩家可以使用自定义活动和手动时长，不保证内置信息适用于 Mod。
- 日程分享是后续产品方向，具体形态未定。

## 状态边界

这些方向是用户已确认的建图背景，不代表后续决策问题已经解决。
尚未验证游戏数据来源、数据复用条件、耗时估算可行性或任何实现方案。
